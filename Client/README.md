# 🛡️ Nirapod Bangladesh Songstha

A modern, responsive, and scalable MERN Stack web application developed for **Nirapod Bangladesh Songstha**. The platform is designed to digitally manage organizational activities, provide secure user authentication, and deliver a seamless experience for administrators and members.

## 🌐 Live Website

**Website:** https://www.nirapodbangladesh.org/

## 📂 Repository

**GitHub:** https://github.com/Razzak118348/nirapod-bangladesh

---

# 📌 Project Overview

Nirapod Bangladesh Songstha is a full-stack organizational management platform that enables secure user management, role-based access control, and efficient content management through a modern web interface.

The application focuses on:

- Secure Authentication
- Responsive User Experience
- Modern UI/UX
- REST API Integration
- Role-Based Access Control
- Scalable Architecture

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Razzak118348/nirapod-bangladesh.git
```

Go to project directory

```bash
cd nirapod-bangladesh
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Build production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
